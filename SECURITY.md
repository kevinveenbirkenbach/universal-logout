# Security Policy

## Supported Versions

Only the latest release receives security fixes. The `latest` image tag always
points at it.

## Reporting a Vulnerability

Please do not report security issues in a public issue or pull request.

Report them privately through either channel:

- GitHub: [report a vulnerability](https://github.com/kevinveenbirkenbach/universal-logout/security/advisories/new)
- Email: Kevin Veen-Birkenbach, [kevin@veen.world](mailto:kevin@veen.world), [veen.world](https://veen.world)

Include the affected version or image tag, the steps to reproduce, and the
impact you expect.
